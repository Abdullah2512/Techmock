# TechMock AI

## Setup
- server: `cd server && pnpm install && pnpm test`
- ai-service: `cd ai-service && pip install -r requirements.txt && uvicorn app.main:app --reload`
- client: `cd client && npm install && npm run build`

Migrations: `cd server && pnpm run migrate`
